# SP ESP32‑S3 1.54 MUMA

Descrizione prodotto e funzionalità: scheda con display ST7789 1.54" e supporto wake‑word; vedi link prodotto nel file originale.

## Compilazione

```bash
idf.py set-target esp32s3
idf.py menuconfig
idf.py build
```

Selezionare: `Xiaozhi Assistant` → `Board Type` → `Spotpear ESP32-S3-LCD-1.54-MUMA`
