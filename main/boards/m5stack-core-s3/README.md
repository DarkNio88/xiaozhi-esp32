# Istruzioni

**Compilazione**

```bash
python ./scripts/release.py m5stack-core-s3
```

Per compilare manualmente, consultare `m5stack-core-s3/config.json` e modificare le opzioni corrispondenti in `menuconfig`.

**Flash**

```bash
idf.py flash
```

> [!NOTE]
> Per entrare in modalità di download: tenere premuto il pulsante di reset (circa 3 secondi) finché il LED interno diventa verde, quindi rilasciare il pulsante.
