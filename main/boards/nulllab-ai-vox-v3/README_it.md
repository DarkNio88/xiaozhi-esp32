# NULLLAB AI‑VOX3

## Panoramica

AI‑VOX3 è una scheda orientata a interazione vocale AI con MCU ESP32‑S3R8, 16 MB Flash, supporto audio ad alta fedeltà e interfacce estese (LCD, SD, microfonia, altoparlante). È pensata per prototipazione rapida e integrazione con estensioni motor/IO.

## Caratteristiche principali
- Processore: ESP32‑S3R8
- Memoria: 16 MB Flash integrata, 8 MB PSRAM
- Interfacce: Type‑C (programmazione/alimentazione), LCD SPI, doppio microfono, amplificatore audio
- Boot/Power: pulsante Power unificato per avvio/reset/spegnimento

## Uso
Supporta ESP‑IDF, Arduino e altri toolchain; per i dettagli consultare il README originale.
