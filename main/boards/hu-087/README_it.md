# HU‑087 (kit formato orologio)

Prodotto: link al venditore (Aliexpress) nel file originale.

## Programmazione

Prima di assemblare il prodotto, rimuovere la batteria dalla scheda per accedere al connettore di programmazione. È necessario un programmatore ESP32 che controlli i segnali EN e IO0. Il connettore USB integrato non è cablato ai pin USB dell'ESP32‑S3 e serve solo per la ricarica.
