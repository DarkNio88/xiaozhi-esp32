# Comandi di configurazione e compilazione

**Imposta il target di compilazione su ESP32:**

```bash
idf.py set-target esp32
```

**Apri menuconfig:**

```bash
idf.py menuconfig
```

**Seleziona la scheda:**

```
Xiaozhi Assistant -> Board Type -> Breadboard ESP32 DevKit
```

**Compilazione:**

```bash
idf.py build
```
