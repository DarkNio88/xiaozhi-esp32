# Waveshare ESP32-P4-WIFI6-Touch-LCD-3.5

Scheda della serie ESP32‑P4 + co‑processore ESP32‑C6 con display touch da 3.5".

## Configurazione

```bash
git clone https://github.com/78/xiaozhi-esp32.git
cd xiaozhi-esp32
idf.py set-target esp32p4
idf.py menuconfig
# Selezionare: Xiaozhi Assistant -> Board Type -> Waveshare ESP32-P4-WIFI6-Touch-LCD-3.5
idf.py build
```
