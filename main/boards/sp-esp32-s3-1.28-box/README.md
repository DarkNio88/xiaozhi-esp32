# Comandi di compilazione e configurazione

**Imposta il target di compilazione su ESP32S3:**

```bash
idf.py set-target esp32s3
```

**Apri menuconfig:**

```bash
idf.py menuconfig
```

**Seleziona la scheda:**

```
Xiaozhi Assistant -> Board Type -> Spotpear ESP32-S3-1.28-BOX
```

**Compila:**

```bash
idf.py build
```
