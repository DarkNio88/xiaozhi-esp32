# Comandi di configurazione e compilazione

**Configura il target di compilazione su ESP32:**

```bash
idf.py set-target esp32
```

**Apri menuconfig:**

```bash
idf.py menuconfig
```

**Seleziona la scheda:**

```
Xiaozhi Assistant -> Board Type -> AtomMatrix + Echo Base
```

**Compilazione:**

```bash
idf.py build
```
